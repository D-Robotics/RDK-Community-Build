# Christmas Robot — Xmas Robots 🎄

**Merry Bots-mas! Build a Christmas robot with RDK. Make it move. Share your build.**

[Registration form](https://docs.google.com/forms/d/e/1FAIpQLSfuGT52LJ6RNDt2Abgb-7JMta5jRFOFBrk_4JrWJK3iXJwx9w/viewform?usp=publish-editor) · [Key dates](#key-dates) · [What to submit](#what-to-submit) · [Community and support](#community-and-support)

Registration opens on **November 9, 2026**. Project submissions close on **December 20, 2026**.

Xmas Robots is a Christmas-themed open developer campaign by D-Robotics. Use RDK to build your own Christmas robot, share the build in public, and join a growing open-source robotics community. Your project stays in your own repository; this hub aggregates and showcases community builds.

## Who can participate

- Makers, robotics and AI developers, and technical creators interested in embodied AI and robotics worldwide.
- Individuals and teams, with no limit on team size.
- **RDK hardware is required**, for example an RDK X5.

## Key dates

| Date | Milestone |
| --- | --- |
| **November 9, 2026** | Campaign launch and registration opens |
| **November 23–December 20, 2026** | Hack period |
| **December 20, 2026** | Submission deadline |
| **December 23, 2026** | Final Show & Tell |

## What to build

Your project must meet three requirements:

1. **Built on RDK**, making use of its capabilities.
2. **Include a Christmas element**, such as a Santa hat, reindeer, snowman, Christmas tree, gift, or festive lights.
3. **The robot moves.**

## How to participate

1. Register using the [registration form](https://docs.google.com/forms/d/e/1FAIpQLSfuGT52LJ6RNDt2Abgb-7JMta5jRFOFBrk_4JrWJK3iXJwx9w/viewform?usp=publish-editor) when registration opens on November 9.
2. Join the official D-Robotics Discord server and find **#rdk-community-build**.
3. Create a thread for your project titled **`Xmas Robots-xx/xx/xx(date)-name`**.
4. Build your Christmas robot and share work in progress with the community.
5. Prepare your project repository and a 30-second demo video by December 20.
6. Join the Final Show & Tell on December 23.

## What to submit

Each participant or team submits **two deliverables**:

### 1. Your GitHub repository

Host the project under your own account or team. **No submission or pull request to this official repository is required.**

Your README is recommended to include:

- Project overview
- Demo video and project photos
- Features
- Bill of materials (BOM)
- **How RDK is used — required**
- System architecture
- Future ideas
- Source code

The **How RDK is used** section is required so the community and official showcase can represent your project properly.

### 2. A demo video

Record a **30-second video** that clearly presents the finished Christmas Robot in action, including its movement.

## Community and support

Use **#rdk-community-build** on the official D-Robotics Discord server for technical Q&A, troubleshooting, work-in-progress sharing, and project discussion. Keep updates in your project thread so others can follow your build.

[RDK Community Build](../README.md) is the official project hub for aggregating and showcasing community developer builds. Every developer keeps ownership and maintenance of their own repository.
